# Prelim Project Mini E-Commerce Shopping Cart (TechEase)
A simple e-commerce website (Gadgets) where patterns are implemented such as Creational Pattern (Factory), Structural Pattern (Decorator), and Behavioral Pattern (Observer). The mini e-commerce website can demonstrate add to cart, search bar functional, checking out of products, increasing and decreasing of quantatiy, discounted products, option to select gift wrap, 2 year warrranty, discounts, this demonstrate how patterns work, and implemented.
